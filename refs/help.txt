wdym — prompt rewriter for Claude Code and Codex

Applies structured rewrite principles to a prompt to make it sharper and better
scoped, then submits the enhanced version. Detects prompt type (code, question,
text-gen) and loads matching principles on top of the universal base. Runs either
on every prompt (hook) or only when you ask for it (on-demand) — your choice at
/wdym --init.

Commands are written "/wdym" below. On Codex, type "$wdym" instead; everything
after the prefix is identical.

COMMANDS
────────────────────────────────────────────────────────────────────
  /wdym <prompt>                     Rewrite this prompt now
  /wdym --init                       Set up or reconfigure: scope + activation
  /wdym --status  (--stats)          Usage report: prompts seen, transform rate, by-type
  /wdym --set-mode --flash           Permanently switch to flash mode
  /wdym --set-mode --comprehensive   Permanently switch to comprehensive mode
  /wdym --help                       Show this message

INIT FLAGS  (skip the matching question)
────────────────────────────────────────────────────────────────────
  --global                           Apply to all projects (user scope)
  --local                            Apply to this directory only (Claude Code
                                     only; Codex is global-scope only)
  --hook                             Fire automatically on every prompt
  --on-demand                        Fire only when invoked

INLINE FLAGS  (drop anywhere in a prompt)
────────────────────────────────────────────────────────────────────
  --flash                            Switch to flash mode and continue with this prompt
  --comprehensive                    Switch to comprehensive mode and continue
  --global                           Force universal principles, skip type detection

ACTIVATION  (when it fires)
────────────────────────────────────────────────────────────────────
  hook                               Runs on every substantive prompt via a
                                     UserPromptSubmit hook. Skips slash commands,
                                     prompts of 5 words or fewer, follow-ups, and
                                     prompts already well-formed enough that a
                                     rewrite would not improve them.
  on-demand                          Runs only via /wdym or when you ask to
                                     improve/enhance/rewrite a prompt.

  Change it with "/wdym --init --hook" or "/wdym --init --on-demand" — this moves
  the hook wiring too. Editing pref.json by hand only changes half the setting.

RUN MODES  (how it behaves once it fires)
────────────────────────────────────────────────────────────────────
  comprehensive  (default)           Shows only the rewritten prompt; one gate:
                                     run enhanced / run original / edit
  flash                              Rewrites and fires immediately — no gate

PROMPT TYPES  (auto-detected)
────────────────────────────────────────────────────────────────────
  code                               Coding tasks, bugs, refactors, API work
  question                           Explanatory or conceptual questions
  text-gen                           Summaries, drafts, translations, emails
  (none)                             Falls back to global principles only
